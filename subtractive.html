Subtractive synthesizer

Owner: Joe Nguyen. It starts with a harmonically rich wave, then filters it and shapes it over time. Every level of the grading rubric is supported.

Wave tables

CBandLimitedTables holds sawtooth, square, triangle, and pulse waves. The pulse wave is the optional fourth wave, and it stays high for 25% of each cycle.

Each wave has 10 tables of 4,096 samples, one per octave. A table contains only the harmonics that stay below 20 kHz for the highest note using it, so high notes don't alias. A note uses the first table that covers its pitch.

Harmonic levels are 1/h for sawtooth, 1/h on odd harmonics for square, sin(0.25πh)/h for pulse, and s/h² on odd harmonics for triangle, where s alternates between 1 and -1. Each table is scaled to a peak of 1.

The spec suggests a separate offline program for making tables. We build them once in code when the first note starts, and notes then only read from them, without calculating the waveform for each sample.

Pitch

A phase value tracks the position in the wave cycle. It advances by frequency / sample rate each sample, so higher notes move through the table faster. Linear interpolation fills in values between table entries.

Envelopes

CADSR produces one level from 0 to 1 per sample, moving through attack, decay, and sustain until the note's duration ends. The release then fades from the current level to 0, even if the note ended early, which prevents clicks. A note finishes when its amplitude release ends, so release time extends past the note's duration.

Polyphony

The sequencer creates a separate CSubtractiveInstrument for each note, with its own phase, envelopes, and filter state. Any number of notes can start and stop independently, and the mixer adds them together.

Reson and the Moog sound

CReson is a two-pole recursive filter:

y[n] = g·x[n] + 2R·cos(θ)·y[n-1] - R²·y[n-2]
θ = 2πf / sample rate
R = exp(-π·bandwidth / sample rate)

The poles create the resonant peak at frequency f. Instead of the usual gain that normalizes the peak, the gain is set so that low frequencies pass at full level, which keeps the bass of a note under the moving peak and sounds closer to a Moog than a plain band-pass filter. To keep narrow peaks from getting too loud, the output is then reduced by the square root of the peak gain.

Filter envelopes

Each note has a second CADSR that drives the filter. Its level moves the Reson frequency between cutoff and peak on a log scale, recalculated every sample:

f = cutoff × (peak / cutoff)level

A fast envelope gives the bass plucks their snap from bright to dark, and a slow one gives the pad and wah bass their long sweeps.
