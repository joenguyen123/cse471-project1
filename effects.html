Effects

Owner: Zachary Roseman. Four effects run in parallel, and the score controls how much of each note goes to each one. Every level of the grading rubric is supported.

This 14 second demo uses audio from the subtractive synthesizer only. Download the WAV or the score.

Effects sends

Every note has a dry level (default 1) and four send levels, send1 to send4 (default 0). For each frame, CEffectsMixer multiplies each instrument's output by those levels and adds it to the dry bus and four effect buses.

Each effect processes its own bus, and the final frame is the dry bus plus all four effect outputs. So one note can stay dry while the next goes only to reverb. This routing is in the shared system, with each effect as its own class derived from CEffect.

Effect objects last for the whole song instead of being created per note. Each one receives one stereo frame at a time.

Ring modulation (slot 1)

CRingModEffect multiplies the input by a sine wave: out = in × sin(phase). This replaces each frequency with its sum and difference from the sine, giving a metallic, out-of-tune sound. frequency sets the sine in Hz. The default is 100, and the song and demo use 300.

Chorus (slot 2)

CChorusEffect outputs a copy of the input delayed by a slowly changing amount, which slightly bends its pitch. Mixed with the dry signal, it sounds like several players. The delay is 20 ms, varying by 4 ms at 0.8 Hz, in opposite directions on the left and right to widen the sound. Linear interpolation reads the fractional delay from a 0.1 second buffer. The song and demo use the defaults for delay, depth, and rate.

Flanging (slot 3)

CFlangeEffect uses a much shorter delay: 3 ms, varying by 2 ms at 0.5 Hz. It outputs half the input plus half the delayed signal, and that interference creates notches in the sound that sweep up and down. Part of the delayed signal is fed back into the delay line to make the notches stronger. This effect's output includes the input so the sweep is audible even with dry="0". feedback defaults to 0.3, and the song and demo use 0.6.

Reverb (slot 4)

CReverbEffect uses a 0.2 second delay line per channel with three reflections at 29, 43, and 67 ms, mixed at 0.55, 0.35, and 0.20. The mix is fed back into the delay line, scaled by decay, and the reflections pile up into a fading tail. The output is half the mix. decay defaults to 0.55, and the song and demo use 0.75, producing a longer, more noticeable reverb tail. roomSize scales the reflection times and stays at its default of 1.

The synthesizer keeps rendering for 2 seconds after the last note so the tail can finish.
